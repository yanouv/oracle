# Modeling and Forecasting Volatility : Empirical Evidence from Oracle
Estimation of different models to study and forecast daily stock returns volatility of a Big Tech company.
## Abstract
This work investigates the modeling and forecasting of financial volatility using daily returns of Oracle Corporation. The analysis combines several families of models, including GARCH-type specifications for conditional volatility, as well as CAViaR and GAS models for tail-risk estimation. The objective is to identify models describing accurately the observed volatility and being able to forecast future volatility. All was coded in R Studio.
